Five finance-admin agents that stop at an approval queue

Invoicing, bills, payroll, GST/HST and bookkeeping for a Canadian small business. Claude reads the messy documents through schema-forced tool calls; tax, payroll and file-format maths is plain tested code; and nothing is posted, paid or filed until a person approves it.

Every figure on this site comes from a dry run of the five agents and from evals/run_all.py, built {{ built }}. Scores are for the deterministic rules baseline; Claude has not been scored yet.

Architecture

Each agent reads documents, proposes changes and stops. The approval gate in shared/approvals.py is the only way anything reaches the ledger or an output file.
